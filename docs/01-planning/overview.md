# RoadDash 기획

## 무엇을 만드는가

아래에서 위로 이어지는 구불구불한 도로를 따라 질주하는 **엔들리스 레이싱 게임**. 엔딩은 없고,
얼마나 오래 살아남아 높은 점수를 기록하느냐가 전부다.

설계 기준은 두 단어다. **단순하고 어렵게.**

- 단순함: 조작은 좌우 한 축뿐이다. 규칙 설명이 한 문장으로 끝난다 — "도로 위에서 장애물을 피해라".
- 어려움: **한 번이라도 부딪히면 그 판은 끝난다.** 장애물 충돌과 도로 이탈 모두 즉사다.

## 규칙

| 항목 | 내용                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 조작 | 키보드 ←→ 또는 A/D 홀드, 터치·마우스는 드래그(손가락 쪽으로 차가 끌려온다) |
| 죽음 | 장애물 충돌 또는 도로 이탈 시 즉시 종료                                    |
| 점수 | 주행 거리 10px당 1점                                                       |
| 시작 | 첫 조작 전까지 세계가 멈춰 있다 — 화면이 뜨자마자 죽는 일이 없도록         |
| 기록 | 개인 최고 점수를 `roaddash.best`에 저장 (게임 포털이 읽는 규약)            |

## 난이도 — 한 번에 한 축씩

레벨은 1,000px마다 오른다. 레벨업은 **네 축을 돌아가며 하나씩** 조인다.

| 순번 | 축          | 무엇이 바뀌나 | 시작 → 상한                         |
| ---- | ----------- | ------------- | ----------------------------------- |
| 1    | 속도        | 스크롤 속도   | 260 → 620 px/s                      |
| 2    | 장애물 밀도 | 행 간격       | 420 → 210 px                        |
| 3    | 도로 폭     | 도로 반폭     | 168 → 102 px                        |
| 4    | 커브        | 진폭·주기     | 52 → 130 px, 0.0042 → 0.0078 rad/px |

한 번에 하나만 바꾸는 이유는 두 가지다. 플레이어에게 **무엇이 어려워졌는지 말해줄 수 있고**
(레벨업 토스트가 축 이름을 띄운다), 밸런싱할 때 축 하나를 건드려도 나머지 셋의 체감이 변하지
않는다.

회전은 **레벨 28**에서 모든 축이 상한에 닿으며 끝난다. 속도 스케줄로 적분하면 **약 65초** 지점이고,
잘하는 플레이어가 60~120초 사이에 죽는 것이 목표치다. 이 수치는 `tests/difficulty.test.ts`가
검사한다 — 튜닝 값을 바꾸면 테스트가 먼저 반대한다.

### 그 뒤: 꼬리

회전이 끝났다고 난이도가 멈추면 하이스코어 게임은 인내력 시합이 된다. 그래서 레벨 29부터는 **두
개의 꼬리 축**이 같은 방식으로 번갈아 올라간다.

| 꼬리 축 | 무엇이 바뀌나                                     | 상한    |
| ------- | ------------------------------------------------- | ------- |
| 빈틈 폭 | `gapSlackRatio` 0.55 → 0.15 (평균 빈틈 95 → 67px) | 레벨 45 |
| 행 간격 | 210 → 120px (행 사이 0.34 → 0.19초)               | 레벨 59 |

꼬리는 **런을 강제로 끝내지 못한다.** 공정성 불변식이 지켜지는 한 완벽한 플레이어는 영원히
살아남는다 — 그게 공정하다는 말의 뜻이다. 꼬리가 줄이는 것은 사람의 실수 여유다: 차 양옆 30px가
16px가 되고, 한 행을 읽을 시간이 0.34초에서 0.19초가 된다.

### 초반 빈틈 바닥

빈틈 폭은 합법 범위 안에서 균등 분포라, 아무 장치가 없으면 **레벨 1의 첫 행이 레벨 29만큼 좁을 수
있다** — 실제로 열 행에 한 번꼴로 그랬다. 차가 키에 어떻게 반응하는지도 모르는 상태에서 만나는
난이도다. 그래서 빈틈 하한을 레벨 1에서 126px로 시작해 레벨 13까지 안전 최소치(56px)로 감쇠시킨다.
난이도 축이 아니라 온보딩 장치이므로 회전에 참여하지 않는다.

## 점수 — 어려운 구간이 더 비싸야 한다

거리만으로 점수를 매기면 **가장 어려운 행이 가장 싸다.** 행 간격이 레벨 1에서 420px, 상한에서
210px이므로, 게임에서 제일 어려운 행을 통과한 대가가 제일 쉬운 행의 정확히 절반이었다.

그래서 레벨 배수 `1 + 0.06 × (레벨-1)`을 곱한다. 상한(레벨 28)에서 2.6배가 되어 행당 단가가 21점 →
56점으로, 레벨 1의 42점을 넘어선다. 회전을 끝까지 밟은 런은 약 5,300점이다.

`pxPerPoint`와 마찬가지로 이 값은 **기록이 하나라도 쌓이면 못 바꾼다** — 같은 `roaddash.best` 키
아래의 옛 점수와 비교가 불가능해지기 때문이다.

## 공정성

"어렵다"와 "불공정하다"는 다르다. 통과할 수 없는 배치가 하나라도 나오면 그 판의 점수는 실력이
아니라 운이 된다. 그래서 세 가지 불변식을 코드가 **구조적으로** 보장한다 — 자세한 내용은
[ADR-005](../02-architecture/adr-005-난이도-축-회전과-공정성-불변식.md).

## 하지 않기로 한 것

- **목숨·부활 없음.** 한 번 부딪히면 끝. 긴장감이 이 게임의 전부다.
- **아이템·부스터 없음.** 조작이 한 축이라는 단순함을 지킨다.
- **사운드 없음** (현재). 시각 피드백만 있다.
- **글로벌 랭킹 없음.** 서버가 없다. `ScoreService` 뒤에 숨겨 두었으니 나중에 구현체만 추가하면 된다.
