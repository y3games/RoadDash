# RoadDash

끝없이 이어지는 구불구불한 도로를 위로 질주하는 반사신경 레이싱 게임.
**한 번이라도 부딪히면 끝**이고, 얼마나 멀리 가느냐가 점수입니다.

플레이: **https://y3games.github.io/RoadDash/**

## 조작

| 입력                 | 동작                            |
| -------------------- | ------------------------------- |
| ← → 또는 A / D       | 누르고 있는 동안 좌우로 조향    |
| 터치 · 마우스 드래그 | 손가락(커서) 쪽으로 차가 끌려옴 |

첫 조작을 하기 전까지 세계는 멈춰 있습니다. 도로를 벗어나도, 장애물에 닿아도 즉시 종료입니다.

## 난이도

1,200px마다 레벨이 오르고, 레벨업은 **네 축을 돌아가며 하나씩** 조입니다.

속도 → 장애물 밀도 → 도로 폭 → 커브 → 다시 속도…

무엇이 올랐는지는 화면에 뜹니다(`LV 7 · 도로 좁아짐`). 레벨 29에서 모든 축이 상한에 닿고,
거기까지 약 78초입니다. 그 뒤로는 난이도가 평탄한 순수 반사신경 구간입니다.

자세한 설계는 [docs/01-planning/overview.md](docs/01-planning/overview.md)를 보세요.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173/
npm run check    # tsc + eslint + vitest — 완료 조건
npm run build    # dist/ 생성
```

개발 중에는 `?seed=123`으로 같은 트랙을 반복 재생할 수 있습니다.

## 구조

게임 전체가 Phaser 없이 돌아갑니다. `src/game/`은 순수 TypeScript이고, 씬은 입력을 모아
`stepWorld()`에 넘긴 뒤 결과를 그리기만 합니다. 그래서 120초짜리 주행을 브라우저 없이
테스트할 수 있고, 실제로 그렇게 검증합니다 — 트랙이 통과 가능한지를 오토파일럿이 증명합니다.

**물리 엔진은 의도적으로 없습니다.** 되살리기 전에
[ADR-004](docs/02-architecture/adr-004-물리-엔진-제거.md)를 읽어주세요.
